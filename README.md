# DAE — Site-77
Site statique (HTML/CSS/JS), sans dépendance externe, publié avec GitHub Pages.

## Publication
Déposez ce dossier à la racine du dépôt, puis Settings > Pages > Deploy from a branch > `main` / `(root)`.

## Candidatures
Le formulaire envoie les candidatures au webhook Discord défini dans `assets/js/config.js`. Ce fichier est public : si le salon reçoit du spam, supprimez le webhook dans Discord, créez-en un nouveau et remplacez l’adresse dans `config.js`. Si le webhook est supprimé, le formulaire propose automatiquement de copier la candidature.

## À compléter
`mentions-legales.html` : nom ou pseudonyme de l’éditeur et adresse e-mail de contact.
